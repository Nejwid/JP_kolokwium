autor **Dawid Nowak**, aplikacja utworzona na podstawie wiedzy własnej i własnego kodu z poprzednich laboratoriów  
Java Swing aplikacja okienkowa JFrame zawierająca obszar do rysowania JPanel  
- na panelu mozliwe jest rysowanie prostokątów poprzez kliknięcie-przeciągnięcie-puszczenie myszy  
- prostokąty poruszają się "w prawo" i gdy dotrą do krawędzi obszaru, wracają na przeciwną stronę i kontynuują ruch  
- każdy prostokąt jest uruchomiony w swoim własnym wątku
